# Daniel Vélez — Portfolio Web Creativo

Portfolio personal de **Daniel Vélez**, desarrollador web creativo en Guadalajara, México. Un sitio diseñado como experiencia digital inmersiva — no como plantilla.

🌐 **[danielvelez-webdev.com](https://www.danielvelez-webdev.com)**

---

## ✦ Filosofía

> "No solo construyo sitios web; diseño experiencias digitales que inspiran, conectan y transforman."

Cada animación tiene intención. Cada transición cuenta una historia. Cada interacción está coreografiada.

---

## ✦ Stack Tecnológico

| Categoría | Tecnologías |
|-----------|-------------|
| **Core** | HTML5, CSS3, JavaScript ES6+ |
| **Animación** | GSAP (ScrollTrigger, SplitText, Draggable, ScrambleText) |
| **Tipografía** | Fuentes custom (Cloudsters, ChiquetaR, PointPanther, Protage, Logrient, Pronell) |
| **Diseño** | CSS Variables, Temas dinámicos, Glassmorphism, Neon effects |
| **Responsive** | Mobile-first con breakpoints para mobile, tablet portrait/landscape, desktop |

---

## ✦ Características

- **6 temas visuales** intercambiables en tiempo real (Neutro, Acid, Synthwave, Rave, Collage, Holographic)
- **Cursor personalizado** dual (usuario + "Daniel") con reacción a elementos interactivos
- **Modo Caos** — elementos flotando, glitches, partículas aleatorias
- **Modo Creativo** — texto editable en el hero, personalización en vivo
- **Scroll-driven animations** — texto reveal palabra por palabra, parallax, sticky pinning
- **Acordeón liquid glass** con efecto 3D y patrones SVG animados
- **Timeline con cards** estilo naipes que se revelan con scroll pinneado
- **Partículas neon** interactivas con repulsión al cursor (desktop)
- **FAQ** con acordeón accesible (ARIA compliant)
- **Optimizado para SEO** — meta tags, Open Graph, JSON-LD Schema, sitemap.xml

```
PortfolioDV/

│   ├── contacto.css        # Estilos página Contacto
│   └── ...                 # Otros módulos CSS
├── js/
│   ├── main.js             # Init global + registro GSAP
│   ├── cursor.js           # Sistema de cursor dual
│   ├── hero.js             # Animaciones del hero + drag
│   ├── manifiesto.js       # Reveal por palabra + neon highlights

│   ├── sobre-mi.js         # Timeline cards + espiral + CTA
│   ├── contacto.js         # Partículas + reveal + glow
│   └── ...                 # Otros módulos JS
├── gsap-public/minified/   # GSAP plugins (solo los utilizados)
├── Rsc/                    # Recursos (imágenes, fuentes, stickers, SVGs)

├── robots.txt
```

## ✦ Rendimiento & SEO

- Scripts con `defer` para no bloquear el rendering
- `font-display: swap` en todas las fuentes
- Lazy loading en imágenes below-the-fold
- Preconnect a CDNs externos
- Structured Data (JSON-LD Person Schema)
- Meta tags completos (OG, canonical, description) en todas las páginas
- Sitemap XML + robots.txt
